# Root-search method and verification

NEO-RT has two scalar root searches in the orbit/frequency path:

1. VODE locates the first accepted bounce event on its dense ODE
   interpolant.
2. The resonance layer refines each sign-changing pitch bracket returned by
   `driftorbit_coarse`.

## Resonance residual

For a fixed velocity, orbit class, field, and harmonic, define

```text
R(eta) = mth Omega_theta(v, eta) + mph Omega_phi(v, eta).
```

The frequency routines already return the analytic eta derivatives. Therefore

```text
R_eta(eta) = mth dOmega_theta/deta + mph dOmega_phi/deta.
```

The refinement receives one interval `[a,b]` from the coarse sign scan and
keeps the invariant

```text
R(a) R(b) <= 0.
```

It starts with a secant proposal. At each iteration it evaluates `R` and
`R_eta` once, accepts a Newton proposal

```text
eta_new = eta - R(eta) / R_eta(eta)
```

only when the proposal is finite and strictly inside the active bracket. A
non-finite, zero-slope, stagnant, or out-of-bracket proposal falls back first
to a secant proposal and then to the bracket midpoint. If a false-position
proposal fails to halve the bracket, the next proposal is forced to the
midpoint. The residual test is combined with a relative eta-width test; this
is essential near the trapped--passing boundary, where a small frequency
residual can correspond to a large eta error. Thus Newton accelerates simple
roots while the bracket supplies the convergence guarantee and prevents a jump
to a different root outside the supplied cell.

The production refinement deliberately does not repeat the coarse scan. The
coarse scan is the root-counting operation; repeating it in every
`driftorbit_root` call was redundant and dominated root-refinement cost.
Callers that pass an arbitrary interval still receive a sign validation and a
defined negative sentinel for a missing or non-finite bracket.

The exact-grid-root case is represented as a zero-width bracket and returned
without an iteration. This avoids losing a tangential zero because Fortran's
`SIGN(1,x)` maps zero to the positive sign. The returned derivative is kept
with the returned eta so the hard-root Jacobian cannot come from another point.

## Single-well separatrix frequencies

For a smooth, nondegenerate single magnetic well the unresolved region below
`epst_spl` / `epsp_spl` uses a fitted period and unnormalized drift integral,
with `x = abs(eta-etatp)/etatp` and basis `log(1/x), 1, x*log(1/x), x`.
Taking their ratio retains the finite barrier drift limit. Both fits are
anchored at the nearest resolved sample, so they join the existing splines
continuously. Resolved spline points and the transport pitch margins retain
their existing domains. In particular, this does not extend harmonic-weight
integration to machine-adjacent transport roots.

The periodic field scan rejects any geometry with more than one minimum or
maximum, including unequal-barrier composite trapped lanes, with an explicit
error before frequency initialization. Flat/unresolved fields are also
rejected; a smooth nondegenerate barrier remains an input assumption. The scan
has the same 1000 angular samples as flux-surface initialization and cannot
certify structure below that resolution.

`test_separatrix_cosine` compares with independent elliptic-integral periods
and bounded orbit averages for three cosine-well depths, on both sides of the
boundary down to x=1e-15. `test_separatrix_limit` checks the actual field's
barrier drift, trapped/passing logarithmic coefficient ratio, spline joins,
and direct orbits. The physical resonance bisection oracle, fold/capacity
tests and discontinuous machine-width nonroot rejection remain enabled.

The checked-in kernel is generated by the NEO-RT-owned
`tools/symbolics/gen_neort_separatrix_frequency.f90`, using
[fortsym](https://github.com/lazy-fortran/fortsym). Configure with
`-DNEORT_BUILD_SYMBOLICS=ON -DFORTSYM_SOURCE_DIR=/path/to/fortsym`, build target
`gen_neort_separatrix_frequency`, then run `build/gen_neort_separatrix_frequency`
from the repository root. Regeneration was byte-identical with fortsym
7e8ef7abdd90c49bb5f75e2c119e7d181656bcc6.

## Bounce event

The VODE event locator already uses the Illinois safeguarded interpolation
method on the accepted step's dense output. It is therefore already a
bracketed, interpolation-based root solve rather than a fixed-step crossing
estimate. This change does not replace that event contract: the existing
trapped acceptance filter and the passing `+2*pi` turn remain unchanged,
because they define the production orbit-average convention and are covered by
the golden record. A separate counter-passing event-contract change would
require its own physical oracle and golden-data review; it is intentionally
outside this resonance-search PR.

## Literature and provenance

The method is an enclosed-root hybrid in the family established by Brent's
guaranteed-convergence algorithm, with derivative-informed Newton steps inside
the bracket. Algorithm 748 (Alefeld, Potra, and Shi) is the higher-order
enclosing-root reference; it uses inverse quadratic and inverse cubic
interpolation. We retain the simpler Newton/secant/midpoint combination here
because NEO-RT already supplies `R_eta` and because the bracket invariant is
more important than a higher-order interpolation formula near separatrices.

The analytical derivative is not generated by finite differences in the root
solver. In the passing branch the residual expands
`Omega_phi = Omega_tE + Omega_theta/iota + Omega_tB`, so the shared
`Omega_theta` is evaluated once; the existing analytic derivative API supplies
all terms. The resonance oracle independently recomputes roots with plain
bisection from the same coarse brackets over both signs of parallel velocity,
passing and trapped regions, 16 velocities, and harmonics `mth=-12..12`, and
checks the returned Jacobian by a separate centered residual difference on
smooth frequency branches (the finite difference is skipped inside a small
non-differentiable neighborhood of the separatrix).
