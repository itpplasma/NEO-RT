# Generated POTATO kernels

The Fortran sources in this directory are generated by the native Fortsym
program `tools/gc_symbolics/app/gen_potato_kernels.f90` and committed as one
set. Do not hand-edit generated kernels.

Regenerate with:

```text
cd tools/gc_symbolics
fo exec gen_potato_kernels ../../POTATO/SRC/generated
```

The generated kernels contain the action-domain, perturbation, resonance,
frequency-reduction, Jacobian, gap-error, and limiting expressions used by
POTATO. Runtime code supplies domain checks and status handling only.
